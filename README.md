# USAPARTS

Магазин новых и контрактных автозапчастей из США. Каталог, карточки, VIN-заявки, корзина и заказы читают и пишут PostgreSQL. Цены и остатки не подставляются в коде.

Пока в настройках `demoMode=true`, витрина показывает плашку: тестовые карточки, отзывы, сроки и контакты не являются офертой.

## Стек

Next.js App Router, TypeScript, Tailwind, PostgreSQL, Prisma, Redis (с запасным кэшем в памяти), Zod, Auth.js, серверные действия и REST.

## Запуск

```bash
npm install
# PostgreSQL и Redis, см. .env.example
npx prisma migrate deploy
npm run db:seed
npm run dev
```

Проверка:

```bash
npm run typecheck
npm test
npm run build
npm start
npm run smoke
```

## Что уже работает

- Каталог марка → модель → поколение → год → категория → товар.
- Поиск по названию, артикулу и OEM, с похожими написаниями через `pg_trgm`.
- VIN: проверка длины и контрольной цифры, заявка в базе. Расшифровка машины вызывается только при `VIN_DECODER_URL`.
- Корзина в подписанной cookie. Флаг Secure включается, когда `AUTH_URL` начинается с `https://`. На оформлении цены заново читаются из базы.
- Заказ, статусы, промокод, способ доставки без выдуманного тарифа. Последняя единица на складе переводит карточку в «нет в наличии» и сбрасывает кэш страницы.
- Админка: товары, категории, марки, модели, заказы, клиенты, VIN, обращения, остатки, цены, фото, отзывы, SEO, страницы, статьи, роли, CSV/XLSX.
- SEO: свои title, description, canonical, один H1, robots, sitemap index, schema.org, 404 и 410.

Индексируются страницы с опубликованными товарами. Сортировки, текстовый поиск и пустые комбинации года с категорией в индекс не отдаются. Снятая карточка `/product/test-removed-starter` отвечает 410.

## Интеграции

Пустые переменные означают «не подключено», это же написано на сайте:

- `VIN_DECODER_URL`, `VIN_DECODER_API_KEY`
- `PAYMENT_PROVIDER`
- `DELIVERY_PROVIDER`

Оплата не проводится, трек не генерируется, письмо не отправляется.

## Роли

Администратор видит всё. Менеджер ведёт заказы, клиентов, VIN, остатки, цены и импорт, но не пользователей и не SEO-шаблоны. Контент-менеджер ведёт тексты, статьи, страницы и карточки без права менять цену.
