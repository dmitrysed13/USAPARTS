# USAPARTS

Одностраничный сайт подбора и доставки запчастей для американских авто.

Стек: React, Vite, TypeScript, Tailwind CSS, Lucide.

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверка:

```bash
npm test
npm run build
```
