## Техническая проверка

Пройдено на всех 343 опубликованных страницах:

- HTTP 200. Адрес без завершающего слэша, проверенный на `/avtozapchasti/ford/mustang`, отвечает 301.
- Ровно один `<title>`, одно description, один H1. Они совпадают с реестром.
- Title, Description и H1 не повторяются ни у одной пары страниц.
- Один `link rel=canonical` на путь самой страницы.
- `meta robots` = `index, follow`.
- Open Graph title и url совпадают с Title и путём.
- JSON-LD разбирается. У каталога есть `CollectionPage`, `BreadcrumbList`, `Service`, `Organization`, `WebSite`, `ItemList`, `FAQPage`. `Product`, `Offer` и рейтинга нет.
- Ссылки из крошек, карточек и блока «Смежные разделы» ведут на существующие страницы. Битых целей в реестре нет.
- В HTML нет адреса preview-сервера.

Sitemap содержит 343 локатора, ровно список опубликованных страниц. Черновиков в нём нет. Выборочные черновики отвечают 404: Jetta Mk6, `g01/fary/`, X3 F25, Passat `/nms/`, K5 Optima.

Не пройдено:

- Все 343 canonical и `og:url` относительные: `/avtozapchasti/bmw/x3/`, не абсолютный адрес.
- В `robots.txt` нет строки Sitemap. Так и задумано, пока пуст `VITE_SITE_URL`.
- В sitemap локаторы тоже относительные (`<loc>/avtozapchasti/</loc>`). По протоколу sitemap нужен абсолютный URL. В текущем виде файл поисковик не примет.
- Три страницы поколений есть в sitemap, но на них нет входящей ссылки в HTML. Ссылка появляется только после выбора поколения в списке, поэтому краулер её не видит.

Код при отказе не пишет «заявка принята». Телефон для звонка на экране остаётся. Валидация до отправки требует марку, год, деталь и полный телефон. VIN проверяется, только если его ввели.

## Приоритеты

### P0. Критические

1. Доставка заявок не подтверждена. Три реальных отправления закончились ошибкой на экране и HTTP 403 от Cloudflare. Пока письмо не придёт на dmitry.chanoff@gmail.com с обычного браузера, сайт нельзя считать источником заявок.
2. Нет боевого домена в сборке. Canonical, Open Graph и sitemap относительные, в robots нет адреса sitemap. Поисковик такой sitemap не примет. Перед индексацией нужен `VITE_SITE_URL` и повторная сборка.

### P1. Высокий приоритет

1. Три страницы поколений индексируются без уникального текста и без входящей ссылки: Jetta Mk7, X3 G01, X5 G05. Их лучше снять с индекса, пока у каждой не появится собственный абзац и ссылка с модели.
2. 253 категории собраны из одного шаблона. Для продвижения каждой нужен свой угол: что прислать именно по этому узлу и этой модели, без повтора общего коммерческого блока на сотнях URL.
3. Страницы моделей полезнее категорий, но половина текста у них общая. Для конкурентных запросов этого мало.

### P2. Средний приоритет

1. Тормоза и стёкла не опубликованы ни у одной модели. Салон есть у четырёх, охлаждение у десяти, кузов у восемнадцати. Черновики правильно закрыты, но коммерческие запросы этих узлов сейчас попадают на общую модель.
2. Марка существует дважды: `/ford/` и `/avtozapchasti/ford/`, так же у Chevrolet, Dodge, Jeep, Tesla и GMC. Запросы «запчасти Ford» делятся между двумя индексируемыми страницами.
3. Мобильный пункт «Каталог» не открывает каталог моделей.
4. На странице модели «Рассчитать стоимость» не отправляет форму и не открывает окно расчёта. На главной та же подпись открывает окно.
5. У 5 Series список поколений объединяет G30 с соседними, хотя текст просит их не смешивать.
6. Упоминания EcoBoost, 1.4/2.0 TSI и гибридных трансмиссий не опираются на каталог в репозитории. Сейчас они подписаны как ориентир. В индекс лучше не выносить конкретный код, пока его нечем подтвердить.

### P3. Низкий приоритет

1. Фраза про Tiguan «части лет» звучит неясно.
2. Вместо фотографии модели стоит общая схема кузова.
3. Адрес Passat — `/passat/`, в заголовке при этом Passat NMS.
4. Весь каталог входит в один JavaScript размером 393 КБ.
5. Расширенные результаты FAQ для такого сайта Google часто не показывает, даже при корректной разметке.

## Что сделать перед продвижением

Сначала подтвердить, что заявка с телефона владельца доходит на почту, и собрать сайт с настоящим `VITE_SITE_URL`. Затем убрать из индекса три поколения без собственного текста. Категории тормозов, стёкол и остальных черновиков открывать только вместе с отдельным абзацем, не пакетом. После этого имеет смысл идти в Search Console и Яндекс Вебмастер.

Пока пункты P0 не закрыты, заявлять готовность к продвижению нельзя.
