## Проверки

- Title, Description и H1 уникальны на всех 343 страницах. Самый длинный Title — 56 символов, Description — 143.
- Canonical у каждой опубликованной страницы равен её пути. Абсолютным он станет после `VITE_SITE_URL`.
- Schema каталога: `CollectionPage`, `BreadcrumbList`, `Service`, `Organization`, `WebSite`, `FAQPage`, `ItemList`. `Product` и `Offer` отсутствуют.
- Sitemap строится из `pages`. Черновики в него не пишутся. Это проверяется сборкой: число `<loc>` равно числу страниц.
- Внутренние ссылки: главная ведёт в каталог из блока разделов и подвала; страница марки ведёт в свой каталог, если он есть; марка каталога ведёт на модели; модель ведёт на категории, похожие модели, VIN и доставку; категория ведёт обратно на модель. Тест не пропускает ссылку на несуществующий путь.
- Фильтры поколения, года и двигателя не меняют URL.

## Ограничения

- Иллюстрация автомобиля — схема по типу кузова. Фотографию модели можно поставить позже на то же место.
- Коды двигателей и приоритеты категорий — ориентиры для заявки, не подтверждённый каталог совместимости и не статистика спроса.
- Частотность в `seo/keyword_clusters.csv` пустая.
- Форма уходит в FormSubmit. Первое письмо активации нужно подтвердить владельцу ящика, иначе заявки не дойдут.
- Домен, Search Console и Яндекс Вебмастер в репозиторий не подставлены.
- Показ FAQ в расширенных результатах Google не гарантируется самой разметкой.

Тесты: `npm test`. Сборка пишет HTML, `public/sitemap.xml`, `public/robots.txt` и CSV в `seo/`.
