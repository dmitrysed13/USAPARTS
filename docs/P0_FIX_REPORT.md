# Закрытие P0

Дата: 3 ноября 2026 (Минск). Каталог и внешний вид форм не переписывались.

## Что закрыто в коде

Формы больше не ходят на FormSubmit. Заявка уходит на свой адрес `/api/leads/`. Сервер проверяет поля, honeypot, частоту и повтор, и только после этого пытается отправить письмо по SMTP. Сообщение «Заявка принята» появляется только при ответе `{ "ok": true }` и HTTP 200.

Canonical, `og:url`, `og:image`, JSON-LD, sitemap и строка Sitemap в robots собираются из `VITE_SITE_URL`. Сборка без публичного https-адреса останавливается и не записывает относительные URL. `localhost`, `example.com` и `YOUR-DOMAIN` в production-адрес не принимаются. В режиме разработки без переменной canonical остаётся на `http://127.0.0.1:5173` и в production-сборку не попадает.

## Как уходит заявка

1. Браузер отправляет JSON на `/api/leads/`.
2. Пустое скрытое поле `company` отсекает бота: письмо не уходит, человеку форма это поле не показывает.
3. С одного IP принимается не больше 5 попыток за 10 минут.
4. Повтор той же заявки в течение 2 минут после успешной отправки не создаёт второе письмо.
5. Письмо уходит через SMTP на `LEAD_TO`. Если заданы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, то же текст уходит в Telegram. Секреты читаются только из серверного окружения.
6. В журнал пишется результат (`sent`, `rejected`, `limited`, `duplicate`, `unconfigured`, `failed`) без телефона и VIN.
7. Если SMTP не настроен, ответ 503 и на экране остаётся ошибка с телефоном компании.

Тот же обработчик подключён в трёх местах: `server/serve.mjs` для своего сервера, `api/leads.js` для Vercel и `netlify/functions/leads.mjs` для Netlify. Пример nginx проксирует `/api/leads` на порт 8787.

Подбор и расчёт — одна форма. Для неё нужны марка, модель, год, деталь, телефон и VIN или OEM. Заказ звонка по-прежнему требует телефон; на сервер дополнительно уходит адрес страницы.

## Что записать в окружение

Файл-образец: `.env.example`.

- `VITE_SITE_URL` — боевой сайт, `https://домен`, без пути и без слэша в конце.
- `LEAD_TO` — ящик, куда должны приходить заявки.
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`.
- `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` — только если нужно дублировать заявку в Telegram.
- `TRUST_PROXY=1` — если перед Node стоит nginx из примера.
- `PORT` — по умолчанию 8787.

Пароли и токены в репозиторий не добавлялись. Адрес ящика и данные SMTP в этой среде не заданы.

Сборка:

```
VITE_SITE_URL=https://домен npm run build
npm start
```

`public/sitemap.xml` и `public/robots.txt` создаются сборкой и не хранятся в git, чтобы в репозиторий не попал чужой домен.

## Проверки

Автотесты: 27 пройдено. В них есть отказ без SMTP (503), отказ без VIN и OEM (400), одно письмо на повтор, лимит шестой заявки, honeypot без письма и клиент, который не считает ответ без `ok: true` успехом.

Проверочная сборка выполнена с временным адресом `https://audit.usaparts.test`. Это не домен компании, в git он не записан.

На результате сборки:

- 344 HTML, у всех абсолютный canonical и такой же `og:url`.
- У индексируемых страниц `og:image` ведёт на `https://audit.usaparts.test/favicon.svg`.
- Sitemap: 343 уникальных `https://` loc, без localhost, без относительных путей и без 404.
- `robots.txt` содержит `Sitemap: https://audit.usaparts.test/sitemap.xml`, CSS и JS не закрыты, локальных адресов нет.
- Сборка без `VITE_SITE_URL` завершается ошибкой.

Формы на сервере без SMTP:

- Пустая форма Mustang не уходит на сервер и показывает ошибки полей.
- Заполненный VIN-подбор Mustang: HTTP 503, на экране ошибка, успеха нет. Повторная отправка тоже 503, дубль успеха не появился.
- Расчёт с главной (Fusion, OEM, без VIN): HTTP 503 и ошибка на экране.
- Заказ звонка с Honda CR-V: HTTP 503 и ошибка на экране.
- Исключений в консоли браузера не было.

## Доставка письма

Реальное письмо на почту не подтверждалось. В среде нет `SMTP_HOST`, `SMTP_PASS` и `LEAD_TO`, поэтому сервер честно отвечает 503. Подставного успешного ответа не было.

Боевой домен компании в проекте тоже не задан. Проверка абсолютных URL сделана на временном `https://audit.usaparts.test`.

## Что ещё критично для запуска

Код P0 по FormSubmit и относительным URL закрыт. Для запуска остаются два действия владельца: вписать настоящий `VITE_SITE_URL` и выдать SMTP, затем отправить одну заявку с обычного браузера и увидеть письмо. Пока письма нет, источник заявок не подтверждён.

Замечания P1 из `docs/POST_SEO_AUDIT.md` (тонкие страницы поколений и шаблонные категории) этим изменением не трогались.
