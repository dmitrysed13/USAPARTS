# Метаданные каталога

Проверка по сгенерированным страницам из `src/seo/pages.ts`.

| Проверка | Результат |
| --- | --- |
| Уникальные Title | 343 из 343 |
| Уникальные Description | 343 из 343 |
| Уникальные H1 | 343 из 343 |
| Самый длинный Title | 56 символов |
| Самый длинный Description | 143 символа |
| Обрезанное имя модели | нет |
| Одинаковые метатеги у поколений и категорий | нет |

Шаблон Title: `{суть страницы} | USAPARTS`, если строка укладывается в 68 символов. У каталога все Title короче 60.

Description начинается с марки и модели или с названия категории и модели. Хвост про VIN и Беларусь обрезается только если вся строка длиннее 160 символов. В текущем каталоге обрезка не понадобилась.

На каждой странице есть:

- `title` и `meta description`
- `meta robots`: `index, follow` у опубликованных
- `link rel=canonical` на путь страницы
- Open Graph `og:title`, `og:description`, `og:url`, `og:type=website`, `og:locale=ru_RU`
- JSON-LD

Для каталога, марки каталога, модели, категории и поколения тип страницы — `CollectionPage`. Рядом `BreadcrumbList`, `Service`, `Organization`, `WebSite`, `FAQPage` и `ItemList` ссылок. `Product`, `Offer` и `AggregateRating` не выводятся: цены и отзывов с рейтингом в данных нет.

`FAQPage` стоит в разметке как текст вопросов. Показ расширенных результатов Google по FAQ не обещается.

Ручная правка метатегов — через поля модели и функции `titleFor` / `describe` в `src/seo/catalog/buildPages.ts`. Отдельного административного экрана в проекте нет.
