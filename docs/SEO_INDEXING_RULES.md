# Правила индексации

В sitemap и в HTML попадают только элементы `pages` из `src/seo/pages.ts`. Черновики каталога в этот список не входят.

## Индексируются

- Главная, услуги, прежние страницы марок и общие категории.
- `/avtozapchasti/`.
- 19 страниц марок каталога.
- 40 страниц моделей.
- 253 приоритетные категории.
- 3 страницы поколений: Jetta Mk7, X3 G01, X5 G05.

У них `robots` = `index, follow`. Canonical указывает на саму страницу.

## Не индексируются

- 630 черновиков: неопубликованные поколения, пары «поколение + категория» и категории вне приоритета. Адреса нет, ответ — 404 с `noindex`.
- `404.html` закрыт `noindex` и `Disallow` в `robots.txt`.
- Параметры `utm_*`, `gclid`, `yclid`, `fbclid`, `ysclid` для Яндекса снимаются `Clean-param`.
- Выбор года, двигателя и поколения не добавляет query-адрес.

Строка `Sitemap` в `robots.txt` появляется только вместе с абсолютным `VITE_SITE_URL`. Относительный sitemap поисковые проверки не принимают.

## Когда черновик можно открыть

Нужны собственный текст, отличие от соседней страницы и понятный спрос. После этого у поколения ставится `publish: true` или категория добавляется в `priorities`. Сборка сама добавит URL в sitemap и prerender.
