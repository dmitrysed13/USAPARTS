# Семантическое ядро

Файл для загрузки частот: `seo/keyword_clusters.csv`. Колонка `frequency` пустая. Частотность из Планировщика и Wordstat сюда не подставлена.

Один кластер — одна целевая страница. Геомодификаторы «Минск», «Беларусь», «доставка по Беларуси», «заказать в Беларусь» лежат в колонке `geo_modifiers` и не получают отдельные URL.

## Кластеры модели

Запросы «запчасти …», «купить запчасти …», «автозапчасти … из США» и «запчасти … по VIN» ведут на страницу модели.

## Кластеры категории

Запросы узла ведут на страницу категории, если она в приоритете модели. Пример: «бампер Ford Fusion» → `/avtozapchasti/ford/fusion/bampery/`.

Маска «{деталь} {марка} {модель} {год}» остаётся в том же кластере. Годовой страницы нет.

Если категория не в приоритете, `status` равен `draft`, `target_url` — страница модели, `draft_url` — непубликованный адрес. Так запрос не остаётся без живой страницы и не открывает тонкий дубль.

## Кластеры поколений

Отдельный кластер есть у Jetta Mk7, X3 G01 и X5 G05. Остальные поколения указаны в данных модели и в черновиках адресов.
