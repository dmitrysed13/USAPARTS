# Посадочные страницы моделей

Каталог собран из `src/seo/catalog/models.ts`. Новая модель добавляется записью в этот файл и пересборкой. Отдельный JSX на модель не нужен.

Опубликовано 40 моделей. У каждой есть страница модели и 5–8 приоритетных категорий. Страница поколения открыта только там, где поколение отделено своим текстом: Volkswagen Jetta Mk7, BMW X3 G01, BMW X5 G05.

Цены, остатки и карточки товаров не выдуманы. Если готового предложения нет, на странице остаётся форма подбора.

## Что разделено специально

- Passat на этой странице — американский NMS. Европейские B-поколения в тот же URL не смешаны.
- Escape описан как родственник Kuga, но не как тот же автомобиль.
- Rogue не подменяется X-Trail.
- Encore и Encore GX — две модели.
- K5 не смешивается с Optima: Optima остаётся черновиком поколения.
- X3 F25 не публикуется отдельно. G01 опубликован. X5 F15 не публикуется отдельно. G05 опубликован.
- ID.4, Model 3 и Model Y имеют отдельные страницы батареи, электромотора и инвертора.

Коды двигателей в данных — ориентир для заявки. Подтверждение даёт VIN или OEM.

## Как добавить модель

1. Дописать объект в `catalogModels`: марка, slug, короткое отличие от соседней модели, 5–10 категорий, похожие модели.
2. Поколение публиковать флагом `publish: true` только вместе с собственным примечанием.
3. Запустить `npm test` и `npm run build`.

Правка Title, Description и текста делается в `src/seo/catalog/buildPages.ts` для шаблона или полями модели для уникального абзаца. Отдельной CMS в проекте нет: конфигурация и есть редактор.
