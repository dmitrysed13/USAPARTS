# Дальнейшее продвижение USAPARTS

Техническая база собрана. Дальше нужен домен, подтверждение поисковых кабинетов и контент, который нельзя честно написать без новых фактов.

## Перед запуском

1. Выбрать один адрес: `https://домен` без www или с www. Второй должен отдавать 301 на первый. HTTP должен отдавать 301 на HTTPS. Пример для nginx: `deploy/nginx.conf.example`. На Vercel слэш на конце включается файлом `vercel.json`, на Netlify неизвестный адрес отдаёт 404 через `public/_redirects`.
2. Задать `VITE_SITE_URL=https://домен` и пересобрать проект. После этого canonical, Open Graph и `sitemap.xml` станут абсолютными.
3. Открыть письмо FormSubmit на `dmitry.chanoff@gmail.com` и подтвердить форму, если это ещё не сделано. Без этого заявки не доходят.
4. Добавить сайт в Google Search Console и Яндекс Вебмастер. Коды проверки положить в `VITE_GOOGLE_SITE_VERIFICATION` и `VITE_YANDEX_VERIFICATION`, пересобрать и отправить sitemap.
5. В Вебмастере указать регион Беларусь. Отдельного офиса в Минске в реквизитах нет: выдача в Бресте, отправка по стране, включая Минск.
6. Подключить счётчики только боевыми ID: `VITE_GA_MEASUREMENT_ID` вида `G-XXXXXXXX` и `VITE_YM_COUNTER_ID` из Метрики. Пустые переменные ничего не загружают.

## Контент, который стоит добавлять по одному

- Страница модели, когда есть чем она отличается: поколения, какие узлы путают, что прислать.
- Страница «модель + узел» только с конкретной практикой. Капот Mustang и бампер Camaro из ядра ждут именно этого.
- Статья из списка в `docs/SEO_ARCHITECTURE.md`, если она говорит больше, чем уже сказано на услуге.
- Реальные фото пункта выдачи или процесса приёмки. Их же можно поставить в `og:image`. Сейчас картинки для соцсетей нет, чтобы не рисовать фиктивный товар.

Не открывать пачку одинаковых страниц под каждую модель и каждую деталь.

## Что смотреть после индексации

Отдельного кабинета со статистикой в репозитории нет: цифры появятся в Search Console, Вебмастере и Метрике. Раз в неделю имеет смысл сверять:

| Показатель | Где смотреть |
| --- | --- |
| Страниц в индексе и исключённые | Search Console, Вебмастер |
| Показы, клики, CTR, средняя позиция | Эффективность в Search Console, поиск в Вебмастере |
| Органика Google и Яндекса | GA4 и Метрика, каналы по источнику |
| Заявки и конверсия | Цели `form_submit`, `phone_click`, `messenger_click`, `callback_click`, `quote_click`, `form_start` |
| Ошибки индексации, дубли, страницы без Title | отчёты покрытия и выборочный просмотр HTML |
| Битые ссылки | ответ 404 в Вебмастере и свой просмотр новых URL |

Цель `form_submit` срабатывает после успешной отправки на почту. Клик по телефону, мессенджеру, «Заказать звонок», «Подобрать» и первое поле формы пишутся отдельно. Без ID счётчика события остаются в `dataLayer` и никуда не отправляются.

## Чего не делать

- Не ставить рейтинг в разметку, пока нет проверяемого источника оценок.
- Не писать цены и «в наличии», пока позиция не посчитана под конкретный VIN.
- Не закрывать от индекса услуги и марки.
- Не подключать Турбо без отдельной задачи: обычные страницы уже отдают готовый HTML.
