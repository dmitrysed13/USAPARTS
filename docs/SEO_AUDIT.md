# SEO-аудит USAPARTS

Дата проверки: 2 ноября 2026. Объект: одностраничный лендинг на React, Vite и Tailwind до этой доработки.

## Стек

- Клиентский React 19 и Vite 8, без серверного рендера и без предгенерации HTML.
- Стили Tailwind 4, шрифты Manrope и Oswald, иконки Lucide.
- Заявки уходят на `dmitry.chanoff@gmail.com` через FormSubmit.
- Отдельного бэкенда, каталога товаров и домена в репозитории нет.

## Что мешало индексации

| Проблема | Почему это важно |
| --- | --- |
| Весь текст собирался в пустой `#root` только после JavaScript | Google выполняет JS, но исходный HTML был пустым. Яндекс и быстрый просмотр видели только noscript с телефоном. |
| Один URL `/` | Нельзя было ранжировать отдельные коммерческие запросы отдельными страницами. |
| Один Title и Description в `index.html` | Для будущих разделов метатеги были бы одинаковыми. |
| Не было canonical | Любой параметр и зеркало домена могли создать дубль. |
| Не было `robots.txt` и `sitemap.xml` | Роботам не был отдан список канонических страниц. |
| H1 не содержал основной запрос «автозапчасти из США» | Главный экран говорил про оригинальные запчасти и срок, но не про коммерческий ключ. |
| Не было JSON-LD | Организация, адрес и услуги не были размечены. |
| Не было страницы 404 | Несуществующий адрес на статическом хостинге легко превращался в мягкий дубль главной. |
| Форма не собирала модель, VIN, OEM и тип детали отдельными полями | Для подбора по VIN эти данные смешивались с названием детали. |
| Счётчики и подтверждение Вебмастера нельзя было включить без правки кода | Не было конфигурации GA4, Метрики и meta verification. |
| Домен не задан | Canonical и sitemap нельзя честно сделать абсолютными. |
| HTTP → HTTPS и выбор www/без www | Это настройка сервера. В репозитории её не было. |

## Чего в аудите намеренно нет

- Частотности запросов. В проекте нет выгрузки Wordstat или Keyword Planner, поэтому цифры не подставлялись.
- Оценки Lighthouse на момент аудита: замера ещё не было.
- Рейтинга и микроразметки отзывов. Тексты отзывов есть на странице, но независимых оценок, которые можно ставить в schema, нет.
- Товарных карточек. Цен и остатков в проекте нет, Product не размечался.
