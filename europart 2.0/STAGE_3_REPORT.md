# EUROPART 2.0 — отчёт этапа 3

Дата: 3 ноября 2026.

Запрос на этапе оборвался на фразе «сохранять шаблоны импорта для конкретного». Сделаны шаблоны сопоставления колонок для конкретного поставщика. Корзина, оплата, оформление заказа и B2B-кабинет не делались.

## Что добавлено

- Миграция `20261103163000_admin_import_inventory`: почта, телефон, заметка, флаг API и имя переменной ключа у поставщика; `isActive` у склада; `ImportTemplate`, `ImportJob`, `ImportRow`, `AuditLog`. Старые таблицы и триграммные индексы не удалялись.
- Модуль `src/modules/imports/`: разбор, нормализация, проверка, сопоставление, дубли, предпросмотр, запись, откат и отчёт.
- Админка `/admin`: поставщики, склады, категории, бренды запчастей, товары и предложения, импорт, журнал. Вход по `ADMIN_PASSWORD`. Без пароля панель закрыта. Ссылки в публичной шапке нет.
- Проверка API поставщика вызывает уже существующий порт и возвращает отказ. Успешный ответ не имитируется. В базе хранится имя переменной, не секрет.

## Правила записи

Один товар — одна карточка и несколько предложений. Совпадение только по точному OEM или артикулу с учётом бренда. Название товар не склеивает. Импорт новых карточек оставляет черновик. Закупка не подменяет розницу. Артикул хранится строкой.

XLS отклонён: выбранный разборщик ExcelJS безопасно читает XLSX, но не старый двоичный XLS. Файл ограничен 5 МБ, 2000 строками и 40 колонками.

## Проверки

PostgreSQL 16.15 на `127.0.0.1`, базы `europart` и `europart_test`. Docker в этой среде нет, Compose не запускался. Повторный `migrate deploy` новых миграций не нашёл.

Тесты покрывают ведущие нули, CSV, деньги, отказ склеивать по названию, дубли, предпросмотр без записи, два предложения у одной карточки, розницу `50.00` при закупке `12345.67`, отсутствие закупки в публичном JSON и откат. Запрос без куки получает 401.

Временные строки браузерной проверки из базы `europart` удаляются после просмотра. В каталог демонстрационные товары не оставляются.

## Ограничения

- Вход общий, автор журнала — `admin`. Именные роли и Better Auth не подключались.
- Ограничение входа, поиска и VIN хранится в памяти процесса.
- Совместимость с автомобилями в этой админке не редактируется.
- Фото по URL не скачивается.
- `FAILED` оставлен в перечислении статусов и обычным путём не ставится: повреждённый файл не создаёт задание.
