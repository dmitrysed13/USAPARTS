# EUROPART 2.0 — публичный API каталога

Все ответы — JSON. Секреты предложения не сериализуются. Черновики и скрытые категории не возвращаются. Кеш ответа: `Cache-Control: no-store`.

Общий вид товара описан типом `PublicProduct` в `src/modules/catalog/public-dto.ts`. Поля `purchasePrice`, `b2bPrice`, `supplierId`, количество и резерв в него не входят.

## GET `/api/catalog/categories`

Дерево активных категорий: `id`, `name`, `slug`, `description`, `image`, `parentId`, `sortOrder`, `children`.

## GET `/api/catalog/brands`

Активные марки: `name`, `slug`, `logo`, `description`.

## GET `/api/catalog/brands/[slug]/models`

Марка и её активные модели. Неизвестный или неверный слаг: 400 или 404.

## GET `/api/catalog/products/[slug]`

`{ "product": PublicProduct }`. Нет опубликованного товара: 404. Неверный слаг: 400.

Цена есть только если у выбранного предложения заполнена розница. Иначе `price: null`. Наличие без подтверждённого предложения: `unknown`.

## GET `/api/catalog/search`

Параметры проверяет Zod.

| Параметр | Правило |
| --- | --- |
| `q` | 2–80 символов после обрезки пробелов |
| `page` | целое от 1 до 1000, по умолчанию 1 |
| `pageSize` | целое от 1 до 24, по умолчанию 12 |

Ответ: `{ query, page, pageSize, total, items }`. `items` — те же публичные карточки, без подтверждённой совместимости в списке: совместимость есть на странице товара.

Ошибки:

- 400 — короткий или слишком длинный запрос, нечисловая страница.
- 429 — больше 30 запросов в минуту с одного IP. Заголовок `Retry-After`.
- 503 — база недоступна. Пустой каталог так не маскируется.

## POST `/api/vin-requests`

Тело JSON. Успех — только 201 после записи в `VinRequest`. Контакт, IP и текст заявки в ответе не возвращаются. Поля и статусы: `VIN_REQUEST_FLOW.md`.

## Страницы

Серверные страницы вызывают те же репозитории, а не копируют Prisma-модель в браузер.

- `/catalog/`
- `/catalog/[category]/`
- `/brands/`
- `/brands/[brand]/`
- `/brands/[brand]/[model]/`
- `/product/[slug]/`
- `/search?q=`

Фильтры категории и модели передаются query-строкой и применяются на сервере: состояние, тип, наличие, бренд запчасти, розничная цена, сортировка, страница.
