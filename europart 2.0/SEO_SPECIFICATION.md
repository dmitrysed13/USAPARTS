# EUROPART 2.0 — спецификация SEO

Индексация закладывается в маршруты, а не добавляется после запуска. На этапе 1 весь сайт закрыт: `robots.txt` запрещает обход, страницы отдают `noindex`. Открывать обход можно в этапе 7 и только для URL, которые проходят правила ниже.

Частотность запросов здесь не указана. Её нужно снять в Google Keyword Planner, Яндекс Wordstat и отчётах вебмастера. Придуманные «показы в месяц» не используются.

## Язык и география

Один язык: русский. `hreflang` не ставится, пока нет второй языковой версии с тем же смыслом.

Основной город компании — Брест. Формулировка «магазин в Минске» не публикуется, пока нет минской точки. Доставка по Беларуси описывается только подтверждёнными условиями.

Канонический хост берётся из `NEXT_PUBLIC_SITE_URL`. До решения владельца не выбираются одновременно `www` и голый домен.

## Карта URL

Короткие постоянные пути, со слешем на конце в публичной документации и без дубля со слешем и без него. Next.js отдаёт один канонический вид, второй уходит в 301, когда появятся такие пары.

| Назначение                                                     | Путь                                                                                        |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Главная                                                        | `/`                                                                                         |
| Каталог                                                        | `/catalog/`                                                                                 |
| Категория                                                      | `/catalog/{category}/`                                                                      |
| Марки                                                          | `/brands/`                                                                                  |
| Марка                                                          | `/brands/{brand}/`                                                                          |
| Модель                                                         | `/brands/{brand}/{model}/`                                                                  |
| Модель и категория                                             | `/brands/{brand}/{model}/{category}/`                                                       |
| Товар                                                          | `/product/{slug}/`                                                                          |
| VIN-заявка                                                     | `/vin-search/`                                                                              |
| Доставка, оплата, о компании, контакты, отзывы, B2B, FAQ, блог | `/delivery/`, `/payment/`, `/about/`, `/contacts/`, `/reviews/`, `/b2b/`, `/faq/`, `/blog/` |
| Статья                                                         | `/blog/{slug}/`                                                                             |

Не индексируются и не попадают в sitemap:

- корзина, checkout, кабинет, админка, API;
- `/design-system/`;
- результаты поиска и страницы с параметром сортировки;
- фильтры ценой, наличием и комбинацией, у которой нет отдельной редакционной страницы;
- пустые категории, марки и пары «модель + категория»;
- черновики и товары без цены.

Фильтр, который совпадает с отдельным маршрутом марки или категории, не создаёт второй URL. Каноникал фильтра с параметрами указывает на чистый путь раздела. Параметр `page` для второй и следующих страниц списка может индексироваться, если на странице есть свои позиции и свой каноникал на этот номер. Сортировка всегда `noindex` и каноникал на список без сортировки.

Ценная посадочная вроде «тормозные колодки Volkswagen Passat» — это путь `/brands/volkswagen/passat/tormoznye-kolodki/`, а не `?brand=&model=&category=`. Такая страница создаётся, когда есть реальные товары и уникальный текст. Нет товаров — 404, а не «скоро появится».

## Семантика без частотностей

Группы нужны, чтобы развести страницы. Объём спроса предстоит измерить.

Коммерческие, широкие: купить автозапчасти; интернет-магазин автозапчастей; автозапчасти Беларусь; автозапчасти Брест.

Коммерческие, средние: запчасти Volkswagen; запчасти BMW; оригинальные автозапчасти; аналоги автозапчастей; запчасти по VIN.

Коммерческие, узкие: купить {деталь} {марка} {модель}. Это страницы модели и категории.

Информационные: как подобрать деталь по VIN, чем оригинал отличается от аналога, как проходит доставка. Это блог и FAQ, не карточки товаров.

Геозависимые: Брест и Беларусь — на главной, контактах и доставке. Минск не подставляется в шаблон автоматически.

Запросы B2B («запчасти для СТО», «оптовые автозапчасти») ведут на `/b2b/`, а не на розничную категорию.

## Шаблоны

Переменные: `{category}`, `{brand}`, `{model}`, `{name}`, `{article}`, `{partBrand}`, `{condition}`. Город в шаблон товара не подставляется.

| Тип                | Title                                        | Description                                                                               | H1                               |
| ------------------ | -------------------------------------------- | ----------------------------------------------------------------------------------------- | -------------------------------- |
| Категория          | `{category} — купить в Беларуси \| EUROPART` | Что входит в раздел, самовывоз в Бресте и доставка по Беларуси, если условия подтверждены | `{category}`                     |
| Марка              | `Запчасти {brand} — EUROPART`                | Подбор по моделям {brand}, наличие только по реальным предложениям                        | `Запчасти для {brand}`           |
| Модель             | `Запчасти {brand} {model} — EUROPART`        | Модели и разделы, в которых есть товары                                                   | `Запчасти {brand} {model}`       |
| Модель + категория | `{category} {brand} {model} — EUROPART`      | Уникальный абзац плюс список реальных позиций                                             | `{category} для {brand} {model}` |
| Товар              | `{name} {article} — {partBrand} \| EUROPART` | Берётся из описания товара, а не только из шаблона                                        | `{name}`                         |
| Бренд детали       | `Запчасти {partBrand} — EUROPART`            | Кто производитель и какие категории есть в наличии                                        | `Запчасти {partBrand}`           |

Один H1 на страницу. Title и description уникальны среди индексируемых URL. Если после подстановки два URL получают один и тот же title, страница с меньшим содержанием не индексируется.

Шаблон не считается уникальным текстом. Для индексации дополнительно нужно:

- у категории, марки, модели и пары модель+категория — собственный абзац и хотя бы одна опубликованная позиция;
- у товара — описание или характеристики, производитель, артикул, фото с alt, активное предложение с ценой;
- у статьи — законченный текст, не порождённый шаблоном карточки.

## Технические требования

Каждая индексируемая страница: свой title, description, один H1, canonical, человекопонятный URL, хлебные крошки, внутренние ссылки на соседние разделы, код 200. Удалённый товар с преемником — 301. Товар без преемника — 410. Неизвестный адрес — 404.

Open Graph: `og:title`, `og:description`, `og:url`, `og:locale=ru_BY`, `og:site_name=EUROPART`. Картинка только если файл реально есть.

Данные schema.org, когда появятся сущности:

- `Organization` и `WebSite` на главной, с адресом и телефоном из подтверждённой карточки компании;
- `BreadcrumbList` на каталоге, марках и товаре;
- `Product` и `Offer` только у опубликованного товара с ценой и валютой BYN. Наличие берётся из статуса предложения. `Offer` не ставится при пустой цене;
- `SearchAction` не размечается, пока поиск не работает и пока формат поддерживается поисковиками. На этапе 1 его нет.

Sitemap появится в этапе 7 как индекс и отдельные файлы: страницы, категории, марки и модели, товары, статьи. В него не входят фильтры, сортировки, поиск, корзина, кабинет, админка, API и пустые URL.

Пагинация: у каждой страницы свой canonical. В sitemap попадает первая страница раздела. Следующие — по правилу выше, если они не пустые.

Внутренние ссылки: категория ссылается на марки, у которых есть товары этой категории; марка — на модели с товарами; товар — на категорию, производителя и совместимые модели. Ссылка на пустой раздел не ставится.

## Контент

CMS хранит текст раздела, описание марки и модели, FAQ, статью, метаданные, внутренние ссылки и alt. Редактор SEO может менять метаданные, не меняя цену.

Одинаковый абзац, в котором меняются только марка и модель, не публикуется пакетом. Такая заготовка остаётся черновиком шаблона.

Отзывы на `/reviews/` только со статусом публикации и подтверждением. Блок отзывов на главной не заполняется примерами.
