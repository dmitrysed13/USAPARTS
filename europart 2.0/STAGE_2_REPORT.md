# EUROPART 2.0 — отчёт этапа 2

Дата: 3 ноября 2026, 14:40 (Минск).

Этап ограничен базой, каталогом, совместимостью, поиском и VIN-заявкой. Корзина, оплата, кабинеты, админка, поставщики, расшифровка VIN и открытая индексация не делались.

## Схема

`DATABASE_SCHEMA.md` не перенесён целиком. Пользователи, сессии, организации, корзина, заказы, оплаты, отзывы, CMS, журнал и задания импорта оставлены на следующие этапы. Таблицы пользователей не создавались заранее, чтобы не пересечься с Better Auth.

В PostgreSQL созданы:

`Category`, `VehicleBrand`, `VehicleModel`, `VehicleModification`, `PartBrand`, `Product`, `ProductIdentifier`, `ProductImage`, `ProductCompatibility`, `Supplier`, `Warehouse`, `ProductOffer`, `VinRequest`, `SeoMetadata`.

Отдельной связи «товар в нескольких категориях» нет: у товара одна категория, список категории включает потомков. Отдельной таблицы аналогов нет: кросс-номер хранится как `ProductIdentifier`.

Деньги предложения — `Decimal(12,2)`. Это отличается от копеек в модуле `commerce`. Checkout ещё не читает предложения, поэтому два формата не смешиваются в одном ответе.

## Миграция

`prisma/migrations/20261103140000_init_catalog_schema`.

На этой машине Docker не установлен. Миграция проверена на PostgreSQL 16.15, базы `europart` и `europart_test`. Повторный `prisma migrate deploy` новых миграций не нашёл. Команды для Compose записаны в `DATABASE_MIGRATION_GUIDE.md`. Образ Compose с PostgreSQL 17 здесь не запускался.

## API

- `GET /api/catalog/categories`
- `GET /api/catalog/brands`
- `GET /api/catalog/brands/[slug]/models`
- `GET /api/catalog/products/[slug]`
- `GET /api/catalog/search`
- `POST /api/vin-requests`

Публичный JSON не содержит закупку, оптовую цену, поставщика и резерв. Это проверяет тест на карточке с ценами `12345.67`, `999.01` и `50.00`: наружу выходит только `50.00`.

## Страницы

`/catalog`, `/catalog/[category]`, `/brands`, `/brands/[brand]`, `/brands/[brand]/[model]`, `/product/[slug]`, `/search`, `/vin-search`, `/privacy`.

Пустой каталог показывает, что справочник ещё не загружен. Карточка без цены ведёт на заявку. Карточка без подтверждённого наличия не пишет «В наличии». Кнопки корзины нет. Ссылка «Уточнить цену» и кнопка запроса менеджеру открывают форму VIN.

Индексация закрыта: `robots.txt` запрещает весь сайт, страницы отдают `noindex`. Sitemap каталога нет. У страниц есть свои заголовки, канонические пути и хлебные крошки. `SeoMetadata` может заменить заголовок, если строка появится в базе. Пустой шаблон заголовка не подставляется.

## Тесты

`npm run test`: 37 тестов в 12 файлах, включая создание категории и вложенность, марку и модель, товар с несколькими номерами, подтверждённую и скрытую совместимость, точный OEM, артикул, кросс, регистр, пробелы, пустой результат, пагинацию, отсутствие закупки в DTO и API, отказ короткого запроса, отказ VIN без обязательных полей и ограничение частоты.

`prisma validate`, `tsc`, ESLint и `next build` прошли.

В браузере около 15:30 (Минск) проверены пустой каталог, главная на ширине 390 пикселей, сохранение VIN-заявки и карточка без фото, цены и подтверждённого наличия. Кнопка «Уточнить цену» открывает форму с названием и артикулом. Проверочная заявка и временный товар после этого удалены из локальной базы: в `Product`, `Category` и `VinRequest` снова ноль строк. Эта карточка не входит в миграцию и в шаблон импорта.
