# EUROPART 2.0 — статус реализации

Обновлено: 3 ноября 2026, 12:28 (Минск).

Текущий этап: **1 завершён и проверен**. Этап 2 не начат.

## Что сделано

- Проект Next.js в каталоге `europart 2.0`: TypeScript, Tailwind, ESLint, Prettier, Vitest.
- Prisma 7.10.1 подключён к PostgreSQL через драйвер `pg`. Таблиц ещё нет: схема описана в `DATABASE_SCHEMA.md`.
- Docker Compose для PostgreSQL 17 и Redis 7, Dockerfile приложения.
- Модули каталога, подбора, поиска, цен, B2B, склада, интеграций, контента, SEO и админки.
- Правило витринной цены: розница не видит опт, закупку и поставщика. Пустая оптовая цена не подменяется розничной.
- Нормализация артикула.
- Неподключённые интеграции возвращают ошибку, а не пустой успех.
- Дизайн-система и главная с контактами ООО «БелТРЭК». Каталога и корзины нет.
- Индексация закрыта: `robots.txt` и `noindex`.
